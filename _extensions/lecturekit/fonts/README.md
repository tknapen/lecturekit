# Fonts

The paper preset uses TeX Gyre Heros (body) and TeX Gyre Pagella (headings),
with TeX Gyre Pagella Math for equations; the dark preset uses Roboto. The
font files and their licences (GUST Font License; Apache 2.0 or OFL 1.1 for
Roboto) are copied here by the extraction from the course template and
referenced from `_brand.yml` with `source: file`. Until they are in place,
`_brand.yml` names the families and the build relies on the system fonts
that `fonts-texgyre` and `fonts-roboto` provide.
